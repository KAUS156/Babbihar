# Bihar Academic Battle

Bihar's Academic Battle Platform.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Responsive homepage
- 5-image hero slider (1 second rotation)
- 8 academic battles
- Registration
- Student login/dashboard
- Results/certificate pages
- Exam structure
- Admin panel structure
- Firebase placeholders

## Next development
Connect Firebase Authentication/Realtime Database, secure admin rules, live questions, timer, scoring, rankings and PDF certificates.
